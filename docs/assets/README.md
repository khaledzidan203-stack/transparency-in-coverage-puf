# Presentation Assets

This directory contains visual summary assets used by the repository documentation.

| File | Status | Evidence boundary |
|---|---|---|
| `cms-tic-puf-overview.svg` | Current README overview visual | Presentation-only; summarizes evidence already present in the repository |

Presentation assets are not analytical evidence, validation evidence, source data, Power BI report source, or part of the canonical model.

They must not introduce metrics, grains, model structures, or claims that are not supported by governed project evidence. Authoritative claims remain defined by the contracts, canonical datasets, saved PBIP/PBIR/TMDL source, report screenshots, validation evidence, and release controls.
